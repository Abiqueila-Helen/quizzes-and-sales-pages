# Criar nova Landing Page Mobile inspirada na referência

Utilize a imagem de referência anexada (**modelo01-mobile.png**) como base visual para criar uma nova landing page **mobile-first**, mantendo o mesmo fluxo, a mesma estrutura, as mesmas seções e os mesmos textos da imagem referência.

**Importante:** copiar literalmente o design. O objetivo é reproduzir a mesma experiência, organização e hierarquia visual, adaptando a identidade para a marca FigTree.

Cria essa nova página de vendas com a nova rota '/ressignifica-app-sell-pie'
---

## Ajustes necessários

### Remover

- Não criar o header superior ("I am, Blo").
- Não criar a seção do footer com "Conheça todos os nossos aplicativos".

---

## Primeira seção (Hero)

Manter o mesmo layout e a mesma estrutura da referência.

Alteração:

No lugar dos botões da **App Store** e **Google Play**, adicionar botões de chamada para ação que façam scroll até a seção de ofertas.

Exemplos de CTA:

- Quero Recuperar Meus Dias
- Escolher Meu Plano

Os botões devem ter bastante destaque.

---

# Estrutura da página

Manter praticamente a mesma sequência de seções da referência:

1. Hero
2. Demonstração do aplicativo
3. Exemplos
4. Benefícios
5. Depoimentos
6. Seção de Oferta (nova)
7. Garantia
8. FAQ
9. Footer simples

Todos os textos da referência podem ser mantidos.

---

Adaptar toda a página para a identidade visual da FigTree utilizando a seguinte paleta.

## Paleta clara

- #FFFFFF
- #FFCC29
- #CCE7D4

# Elementos decorativos

As ilustrações orgânicas presentes no fundo (folhas, balões, sol etc.) são imagens PNG.

O designer possui liberdade para criar novas variações mantendo o mesmo estilo orgânico e minimalista.

Não é necessário copiar exatamente as mesmas imagens.

---

# Seção de Oferta

Criar uma nova seção de ofertas seguindo o mesmo padrão premium da landing page.

Ela deve ser uma das seções de maior destaque da página.

Adicionar:

- Temporizador de contagem regressiva
- Destaque visual
- Cards premium
- Botões grandes
- Selos de compra segura
- Garantia
- Excelente contraste visual
- Forte hierarquia das informações

---

## Ordem dos planos

Exibir nesta ordem:

1. Anual
2. Trimestral
3. Mensal

---

## Hierarquia dos preços

O maior destaque visual deve ser o **valor mensal equivalente**.

O valor total deve aparecer em tamanho menor como informação complementar.

Exemplo:

### Destaque

**Apenas R$ 3,99 por mês**

### Complemento

Cobrado R$ 47,88 por ano

---

# Estilo geral

A página deve transmitir:

- calma
- acolhimento
- leveza
- sofisticação
- minimalismo
- premium

Inspirar-se no estilo da referência, porém adaptando toda a identidade para a marca FigTree utilizando exclusivamente a nova paleta de cores.

A experiência deve ser totalmente responsiva, priorizando dispositivos móveis, mantendo excelente legibilidade, espaçamento consistente, animações suaves e foco na conversão.
